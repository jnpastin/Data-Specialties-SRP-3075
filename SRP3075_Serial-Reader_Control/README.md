# SRP-3075 Serial Interface and Reader Control

## Overview

This directory contains reverse-engineered schematics and supporting material for the Serial Interface and Reader Control board used in the Data Specialties SRP-3075.

The board provides two primary functions:

- Serial communications
- Reader control and timing

It implements the RS-232 interface used by the serial (SD) model and controls operation of the optical tape reader. It also exchanges punch data, reader and punch control signals, status information, and system timing signals with the Main Logic and Punch Control board.

The schematics were recreated through examination of the board installed in an original SRP-3075. They are not original Data Specialties drawings.

## Function within the SRP-3075

System responsibilities are divided between this board and the [Main Logic and Punch Control](../SRP3075_Main_Logic-Punch_Control/README.md) board.

The Serial Interface and Reader Control board is responsible for:

- Serial communications with the host
- Reader control and timing
- Reader data capture and transmission
- Serial control-character detection and decoding

The Main Logic and Punch Control board provides system coordination, clock and reset generation, punch data processing and buffering, punch control, front-panel handling, parallel interface support, and the primary interconnection point for the machine’s assemblies.

## Serial Communications

The board provides the serial communications functions of the SRP-3075 serial model.

These functions consist of:

- Serial data transfer
- RS-232 configuration and flow control
- Control-character detection and decoding

The serial interface transports data in both directions:

- Data received from the host is converted from serial data into an eight-bit parallel character and passed to the Main Logic and Punch Control board for processing and punching.
- Data obtained from the optical reader is converted from an eight-bit parallel character into serial data and transmitted to the host.

The interface uses 8N1 framing, with one start bit, eight data bits, and one stop bit. Each character therefore occupies ten serial bit times.

## Serial Controller

A TMS6011NC asynchronous communications controller performs the serial-to-parallel and parallel-to-serial data conversion.

### Reader Transmit Path

The eight reader channels enter the TMS6011 on `TI1` through `TI8`.

The TMS6011 loads the reader character and converts it into the serial `TXD_TTL` output. The RS-232 line-interface circuitry then converts that logic-level signal into the voltage levels required by the host interface.

### Punch Receive Path

Serial data received from the host is converted to the logic-level `RXD_TTL` signal by the RS-232 line-interface circuitry.

The TMS6011 converts `RXD_TTL` into the parallel outputs `RXD1` through `RXD8`. These eight data signals cross the inter-board connector to the Main Logic and Punch Control board.

The Main Logic and Punch Control board then performs the punch data processing, buffering, sequencing, and mechanical control required to punch the received character.

## RS-232 Line Interface

The external RS-232 interface is implemented with analog circuitry rather than dedicated integrated RS-232 transceivers.

The line-interface circuitry converts between RS-232 voltage levels and the logic-level signals used by the TMS6011 and surrounding control logic.

The host interface provides:

- Transmitted Data
- Received Data
- Request to Send
- Clear to Send
- Data Terminal Ready
- Low Tape

The interface uses the board’s +12V and -12V supplies to generate and interpret the RS-232 signaling levels.

## Flow Control

The serial interface uses Clear to Send and Data Terminal Ready for flow control.

Clear to Send is provided by the host and controls whether the SRP-3075 may transmit reader data. Removing Clear to Send prevents further reader transmission until the host permits it to resume.

Data Terminal Ready is generated by the SRP-3075 and indicates whether the machine can accept serial data for punching. The host should suspend transmission when Data Terminal Ready is inactive and resume only after it becomes active again.

Request to Send is also used as part of reader selection and operation.

## Baud-Rate Generation and Selection

Reader and punch serial clocks are generated from a 5.0688 MHz crystal oscillator and associated rate-generation, counter, divider, and selection circuitry.

The clock signals supplied to the TMS6011 operate at sixteen times the selected serial baud rate.

The board provides separate baud-rate selections for reader transmission and punch reception.

### Punch Rates

The punch receive path supports:

- 300 baud
- 600 baud
- 750 baud

With ten serial bits per character, these rates correspond to:

- 30 characters per second
- 60 characters per second
- 75 characters per second

The maximum serial receive rate therefore corresponds to the punch mechanism’s maximum operating rate of 75 characters per second.

### Reader Rates

The reader transmit path supports:

- 300 baud
- 600 baud
- 750 baud
- 1200 baud
- 1500 baud
- 2400 baud
- 3000 baud

With ten serial bits per character, the maximum rate of 3000 baud corresponds to 300 characters per second, matching the maximum operating rate specified for the optical reader.

Reader and punch rates are selected using a DIP switch on the board.

## Control-Character Detection and Decoding

When the front-panel Remote Control function is enabled, the board recognizes four ASCII device-control characters:

| Character | Function |
|---|---|
| DC1 | Start reader |
| DC2 | Start punch |
| DC3 | Stop reader |
| DC4 | Stop punch |

The function-decoding circuitry detects these values in the received parallel character data and generates the appropriate reader or punch control request.

When Remote Control is enabled, recognized control characters are interpreted as commands rather than ordinary punch data.

When Remote Control is disabled, the characters are treated as ordinary received data and may be punched.

## Reader Control and Timing

The reader-control portion of the board operates the [Decitek optical tape reader](../Decitek_261E7010_Tape_Reader/README.md) module.

Its functions include:

- Reader start and stop control
- Reader-cycle timing
- Tape-step requests
- Detection of valid reader data
- Capture of the eight reader data channels
- Coordination with the serial transmit path
- Tape-low and tape-error processing (if Option G is installed, see [S Series Technical Manual](../DSI_S_Series_Technical_Manual.pdf))
- Switching the +24V supply delivered to the reader module

The Decitek reader performs the optical sensing, signal conditioning, stepper-motor drive, and mechanical tape transport. The serial board controls when the module is powered, when a tape step is requested, when reader data is captured, and when the resulting character is transmitted.

## Reader Power Switching

The board enables or disables the stepper motor on the reader module by switching the +24V supply delivered to it.

The switched supply is identified as `+24V_SW` in the reconstructed schematics.

The serial board does not drive the reader’s stepper-motor phases directly. Phase generation and motor-drive circuitry are contained within the Decitek reader assembly.

Switching the module’s +24V input is one mechanism used by the board to implement reader control. It is not a separate system-level responsibility.

## Reader Sequence

The board coordinates the reader’s read-then-step operating sequence.

A character is sensed while the tape is stationary. The eight reader channels are captured and presented to the TMS6011, which converts the parallel character into serial data for transmission.

The board then requests advancement to the next character position.

Timing circuitry coordinates the intervals required to:

- Initiate a reader cycle
- Capture valid channel data
- Load the serial transmitter
- Request a tape step
- Detect the sprocket indication
- Continue or terminate reader operation

Reader operation is coordinated with the serial transmit state, host flow control, local controls, remote-control commands, and tape-status signals (if installed).

## Reader Direction

The Decitek reader module supports bidirectional tape movement through a direction-control input.

The SRP-3075 does not expose this capability. The direction input is not connected on this board, leveraging the pull-up on the module which forces the reader to operate in one direction.

Direction is therefore not selectable through the serial interface, front-panel controls, or host commands.

## Reader Data Polarity

The Decitek reader supports selectable output polarity through a polarity-control input.

This board provides no signal on the hole polarity input to a fixed logic level so that the modeule's internal pull-up causes a detected hole to be represented as a logical one, or mark.

The alternate configuration, in which a hole represents a logical zero, or space, is not exposed by the SRP-3075.

## Inter-Board Interface

The board connects to the Main Logic and Punch Control board through a 36-position card-edge connector.

The inter-board interface carries:

- Parallel received data, `RXD1` through `RXD8`
- Reader and punch control signals
- Front-panel control states
- Tape-low and tape-error signals (if installed)
- System clock and reset signals
- Serial-board status and coordination signals
- +5V power
- Ground

Power for the serial board is supplied through this connector by the Main Logic and Punch Control board.

The Main Logic and Punch Control board is the primary connectivity hub for the machine. The serial board uses the card-edge connection to exchange the data, control, timing, status, and power connections required by the serial communications and reader-control subsystems.

## Major Board Connections

The major connections are:

- DB-25 connector for the RS-232 host interface
- 36-position card-edge connector to the Main Logic and Punch Control board
- 20-position card-edge connector to the Decitek optical reader

The 36-position card-edge connector carries both power and inter-board signals.

The 20-position card-edge reader connector carries the eight data channels, sprocket indication, control inputs, switched +24V power, +5V logic power, and ground connections required by the reader module.

## Component Reference Designators

The original Serial Interface and Reader Control board did not contain component reference designators.

All component reference designators shown in the reconstructed schematics were assigned during reverse engineering. They are not original Data Specialties designations.

The assigned references provide consistent identifiers for:

- Schematic organization
- Circuit analysis
- Component-location documentation
- Restoration and repair
- Cross-referencing among schematic sheets

The Main Logic and Punch Control board was also unreferenced. Its reconstructed schematics use the same author-assigned reference approach.

## Reverse-Engineering Notes

The schematics were recreated by:

- Identifying components and values
- Assigning component reference designators
- Tracing PCB connections
- Reconstructing connector pinouts
- Following the serial receive and transmit paths
- Analyzing baud-rate generation and selection
- Tracing reader-control and timing circuits
- Identifying control-character detection and decoding
- Comparing the resulting design against the manufacturer technical manual
- Comparing inter-board signals against the Main Logic and Punch Control board and Decitek reader schematics

Signal names were assigned or normalized where necessary to make the reconstructed design understandable and maintainable.

The reverse engineering of the board is considered substantially complete. No programmable logic, firmware, ROM-based control, or inaccessible control logic is present.

## Accuracy and Open Questions

The schematics are believed to accurately represent the examined board. Corrections may still be made as restoration, measurement, and functional testing continue.

Possible remaining areas for investigation include:

- Differences between production revisions
- Undocumented factory modifications
- Prior repairs or field modifications
- Exact identification of components with incomplete markings

No significant functional uncertainties are presently known.

## Safety

The board uses +5 V, +12 V, -12 V, and +24V supplies and switches the +24V input to the reader module.

Before servicing:

- Disconnect the machine from AC power.
- Verify that supply voltages have discharged.
- Confirm connector orientation before reconnecting the board.
- Avoid connecting RS-232 signals directly to TTL-level circuitry.
- Verify reader power and ground connections before testing the reader outside the complete machine.
- Keep clear of the reader transport when switched power is applied.
